# ToothSegmentation
Reproducción de la red ROI basada en el artículo de nature communications.
Nombre del artículo: 《A fully automatic AI system for tooth and alveolar bone segmentation from cone-beam CT images》

https://github.com/ErdanC/Tooth-and-alveolar-bone-segmentation-from-CBCT

Se utiliza el conjunto de datos abierto CTooth:

https://github.com/liangjiubujiu/CTooth
https://www.kaggle.com/datasets/weiweicui/ctooth-dataset
